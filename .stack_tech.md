# STACK TECNOLÓGICA E ARQUITETURA DO PROJETO ACDC

Este documento consolida a arquitetura técnica confirmada da plataforma ACDC (MAPFRE Seguros • BR-INT).

---

## 1. Visão Geral

- **Projeto**: ACDC Platform (Dynamic Underwriting Platform • DUP & Rating Engine • RTE Tronador).
- **Finalidade**: Exploração estruturada de dados atuariais no MongoDB, motor de precificação e tarifação, catálogo de produtos e coberturas, trilha de auditoria e segurança (PECA), controle de acesso de usuários e assistente conversacional atuarial com RAG.
- **Identidade Visual**: NTT DATA Corporativo (Azul `#0066FF`, Dark Navy `#070A12`, bordas `#182338`).

---

## 2. Frontend

- **Framework**: React 19.x com Vite 8.x.
- **Linguagem**: JavaScript (ESModules / JSX).
- **Estilização**: Vanilla CSS com variáveis de tokens globais (`client/src/index.css` e `client/src/App.css`).
- **Ícones**: Lucide React (`lucide-react`).
- **Porta Padrão de Execução**: `5173` (`http://localhost:5173`).
- **Principais Componentes**:
  - `client/src/App.jsx`: Shell da aplicação, header corporativo, status do cluster e roteamento de abas.
  - `client/src/components/RatingEngineTab.jsx`: Construtor visual dual-pane de fórmulas RTE, drag-and-drop de objetos (`VAR`, `CTE`, `FN`, operadores textuais), catálogo atuarial e validação por IA.
  - `client/src/components/AuditTab.jsx`: Trilha de auditoria PECA e histórico de alterações em tabela com modal de diff visual lado a lado.
  - `client/src/components/ChatBotWidget.jsx`: Widget flutuante do assistente ACDC Copilot com integração ao pipeline RAG.
  - `client/src/components/RiskSelectionTab.jsx`: Gerenciamento de regras de subscrição (`RULES`) e seleção de risco (`RS-RULES`).
  - `client/src/components/ProductsTab.jsx`: Catálogo e edição de produtos e coberturas.
  - `client/src/components/ExplorerTab.jsx`: Explorador universal e visualizador JSON de coleções MongoDB.
  - `client/src/components/UsersTab.jsx`: Painel de administração e liberação de perfis de usuário.
  - `client/src/components/LoginModal.jsx`: Modal de autenticação e solicitação de acesso.

---

## 3. Backend & APIs

- **Runtime**: Node.js (v24.x).
- **Framework**: Express.js.
- **Porta Padrão de Execução**: `4000` (`http://localhost:4000`).
- **Autenticação**: JWT (JSON Web Tokens) com alçadas de permissão granular (`requireEditPermission`, `requireRole`).
- **Principais Rotas**:
  - `/api/auth`: Login, solicitação de registro e gestão de perfis (`server/src/routes/auth.js`).
  - `/api/rte`: Fórmulas, dicionário de objetos, conceitos econômicos, bases técnicas e validação sintática (`server/src/routes/rte.js`).
  - `/api/audit`: Registros de auditoria PECA e diff de alterações (`server/src/routes/audit.js`).
  - `/api/products`: Catálogo de produtos e coberturas associadas (`server/src/routes/products.js`).
  - `/api/rules`: Regras de negócio, loss ratio e seleção de risco (`server/src/routes/rules.js`).
  - `/api/explorer`: Leitura e paginação dinâmica de coleções MongoDB (`server/src/routes/explorer.js`).
  - `/api/copilot`: Chatbot conversacional com recuperação RAG (`server/src/routes/copilot.js`).

---

## 4. Banco de Dados & Armazenamento

- **Engine**: MongoDB Community Server 7.0 (local em `mongodb://localhost:27017` ou container Docker).
- **Databases Ativos**:
  - `acdc_dup_br-int`: Subscrição dinâmica, regras de negócio (`RULES`, `RS-RULES`), produtos (`PRODUCTS`), antifraude (`TRIANGULATION_KEYS`), changelog (`AUDIT_CHANGELOG`), auditoria (`PECA`) e vetores RAG (`KNOWLEDGE_BASE_RAG`).
  - `acdc_rte_br-int`: Motor de tarifação Tronador, fórmulas (`FORMULA-DEFINITION`), constantes atuariais (`CONSTANT-DEFINITION`), conceitos econômicos (`ECONOMIC-CONCEPTS`), tabelas de bases técnicas (`TECHNICAL-BASIS-TABLES`) e cotações.

---

## 5. Inteligência Artificial & Gateway Local

- **AI Gateway Local**: `http://127.0.0.1:8766/codex/v1`.
- **Modelos de Raciocínio Suportados**:
  - `gpt-5.6-terra-high` (Modelo principal de alta capacidade lógica).
  - `gpt-5.6-luna-high` (Modelo alternativo para respostas rápidas).
  - `gpt-4o` (Compatibilidade padrão).
- **Modelo de Embeddings**: `text-embedding-3-small` (vetores de 1536 dimensões via `/codex/v1/embeddings`).
- **Pipeline RAG**: Busca híbrida implementada em `server/src/services/ragService.js` (65% similaridade de cosseno vetorial + 35% correspondência léxica com ponderação por códigos atuariais).

---

## 6. Comandos de Inicialização e Operação

- **Subir Banco de Dados via Docker**:
  ```bash
  docker-compose up -d
  ```
- **Iniciar Backend (Node.js)**:
  ```bash
  cd server && npm run dev
  ```
- **Iniciar Frontend (Vite)**:
  ```bash
  cd client && npm run dev
  ```
- **Build de Produção do Frontend**:
  ```bash
  cd client && npm run build
  ```
